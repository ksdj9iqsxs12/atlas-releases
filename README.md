## What is Atlas?

Atlas is an AI-powered trading assistant that combines Vision-Language Models with real-time chart analysis. It runs as a desktop overlay on Windows, connecting to MetaTrader 5 for live trading.

**Key Capabilities:**
- **Neural Vision Analysis** - AI reads charts like a human, identifying patterns and liquidity zones
- **Multi-Mode Trading** - Manual, Semi-Auto, Full Auto, or Sleep mode
- **LLM Strategy Forge** - Generate trading strategies from natural language
- **Risk Guard Protocol** - Institutional-grade drawdown protection
- **Conversational AI** - Chat with your trading AI in natural language

## Features

### Trading Modes

| Mode | Description |
|------|-------------|
| **Manual** | AI suggests setups, you execute |
| **Semi-Auto** | AI manages SL/TP, you confirm entries |
| **Full Auto** | Hands-off execution with your strategies |
| **Sleep** | No new trades, monitors existing positions |

### AI Capabilities

- **Chart Vision** - Screenshots analyzed by vision models
- **Pattern Recognition** - Detects ICT concepts, liquidity zones, order blocks
- **Multi-Model Support** - Works with Ollama, Groq, OpenAI, Gemini, OpenRouter
- **Memory System** - Learns your trading style over time
- **Strategy Generation** - Describe a strategy in English, get Python code

### Risk Management

- Maximum position limits
- Daily loss limits (default 5%)
- Per-trade risk percentage (default 1%)
- Minimum confidence thresholds
- Emergency stop controls

## Quick Start

1. **Download** the installer from [Releases](https://github.com/ksdj9iqsxs12/atlas-releases/releases)
2. **Run** the installer (no admin required)
3. **Start** MetaTrader 5
4. **Launch** Atlas from your desktop
5. **Configure** your AI provider and API keys
6. **Trade** - Chat with your AI or enable auto modes

See [Getting Started Guide](docs/getting-started.md) for detailed setup instructions.
